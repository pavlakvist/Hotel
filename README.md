# Mit Hotel

Mit eget hotel i stil med Habbo, lavet i almindelig HTML, CSS og JavaScript.

## Sådan starter du det
Dobbeltklik på `index.html`, så åbner det i din browser.

## Filerne
- `index.html` – selve siden
- `css/stil.css` – farver og udseende på siden
- `js/indstillinger.js` – **her skifter du grafik, farver, møbler og navn**
- `js/spil.js` – spillets motor (gå, tegne, stille møbler)
- `billeder/` – dine egne billeder (læs `billeder/LAES-MIG.txt`)

## Styring
- Klik på gulvet for at gå.
- Vælg et møbel i panelet, og klik på et ledigt felt for at stille det.
- Klik på et møbel for at vælge det. **R** drejer, **Delete** samler op, **Esc** fortryder.
